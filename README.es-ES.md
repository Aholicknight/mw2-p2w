

# mw2-p2w
***POC para Modern Warfare-II / Warzone 2***

**Todos los offsets y el código aquí han sido actualizados para el último parche del juego. Solo necesita ser compilado. Te lo dejo a tu criterio; he dejado los archivos del proyecto y los archivos .sln para que puedas importar y editar el proyecto por tu cuenta. A continuación hay una lista de las características incluidas; no soy responsable de lo que hagas con esto :)**

¡ASEGÚRATE DE ESTAR EN MODO PANTALLA COMPLETA CON BORDES, DE LO CONTRARIO SE CRASHEARÁ!

Necesitarás el C++ Redistributable:
https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170

# Características:

Aimbot:

- Selección de arma

- Apuntado por memoria

- Activar con tecla (On/Off)


- Huesos objetivo (Cabeza) (Cuello) (Cuerpo) (Más cercano)

- Verificación de visibles

- Suavizado (1-10)

- FOV (1-100)

 Visuals:

- Activar con tecla (On/Off)

- Nombres de jugadores

- Distancia del jugador

- Barra de vida (Constante) (Normal)

- Texto de vida

- Bounding Box (3D) (2D)

- Contornos (Arriba) (Abajo) (Retícula)

- Selector de color
